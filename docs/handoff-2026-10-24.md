## 已验证的事实（实测）

1. **弹出策略**：`Shell 动词（无则缓存跳过）→ 每 0.4 s 请求一次 PnP 移除，最多 10 s`；同一块 USB-SATA 硬盘实测 **4.2~4.6 s**，2~3 次否决后成功；**不改磁盘状态**，弹出后拔插资源管理器直接可读（用户两次复测通过）。
2. 三条对比基线（同机同盘）：脱机→移除 4.0 s（但重插带脱机标记、读不到）；脱机→联机→轮询 16.9 s（10 次否决）。原因：联机会重新挂载卷、重置系统"卷忙"计时器。
3. **`IOCTL_DISK_SET_DISK_ATTRIBUTES` 在这块桥上一律失败**：persist=0/1 × version=16/32 × size=16/32 六种组合全部 `error=24`，所以没有"非持久脱机"可用。
4. **换主题不能刷新磁盘**：`_apply_theme` 重建界面后用 `self._last_disks` 重画列表（`quiet=True` 不重复写日志），磁盘枚举只发生在启动与手动刷新。
5. **图标按钮必须是 Canvas 自绘**（`gui/iconbutton.py`）：ttk.Button + 图片时，底色烤在图标-sized PNG 里，按钮比图标宽 → 热追踪只在图标周围一小块生效；换成 Canvas 面（整块换底色 + 换图）后用户确认"热追踪全部好了"。
6. **Canvas 按钮尺寸与 ttk 文字按钮不一致会翻车**：现在统一取"文字按钮实测高度"（`_button_height()`）作为 Canvas 宽高；带更大字号的文字（问号）也走 Canvas 文字模式，避免 pady 撑大按钮——用户明确要求"字形和按钮尺寸要分开"。
7. **tkinter 字体 size 必须是整数**：`tkfont.Font(size=15.5)` 抛 `_tkinter.TclError: expected integer but got "15.5"`（日志实证）。这就是上一轮"启动后标题变成 tk"的真正原因。
8. **设置窗**：420 逻辑宽、四周 24/20、主题标题在上控件在下、关闭按钮与设置区隔 20；三个主题按钮用同一个 Canvas 控件，热追踪生效。
9. **标题栏**：主窗口 / 设置窗 / 对话框（`gui/dialog.py`）三处都必须**每次按当前主题**调用 `set_dark_titlebar(hwnd, palette.is_dark)`；只设 `True` 不设 `False` 会导致切回浅色仍是黑标题栏。
10. **抓图验收**：`tools/capture_window.py --title ... --pid <pid>`；PyInstaller onefile 的**父进程没有窗口**，要取 `Get-Process SSEject | ? MainWindowHandle -ne 0` 的那个 PID（实测）。

## 需要沉淀到经验库的教训（尚未写）

1. 图片按钮做热追踪：底色烤进 PNG 只在图标大小内生效——**按钮面必须自绘**，否则热追踪永远是"小方块"。
2. tkinter 字体 size 必须整数；写 `+5.5` 会让 `MainWindow.__init__` 抛 TclError，窗口标题停在 `tk`。
3. 图标类改动一次只改一枚、改完立刻抓图；三处一起改会让"崩溃归因"变成整批回滚。
4. 抓图按标题会命中浏览器；onefile 的父进程没有窗口——必须 `--pid` + 取有窗口的子进程。
